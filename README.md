# Escape Room Web Application

Full-stack web aplikacija za escape room, razvijena pomoću **Next.js, React, TypeScript i Supabase**.

## Funkcionalnosti

* Pregled escape room soba
* Registracija i prijava korisnika
* Rezervacija i upravljanje terminima
* CRUD operacije nad rezervacijama
* Kontakt forma i blog
* Responzivni dizajn
* Supabase autentifikacija i baza podataka

## Tehnologije

* Next.js
* React
* TypeScript
* Supabase
